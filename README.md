🌦 Weather With Warm Wishes
A warm, vibrant, and interactive weather web app built with HTML, CSS, and JavaScript. This app shows real-time weather for any city using the WeatherAPI, changes the background based on the temperature, and adds a personal touch with fun advice and quotes.


📸 Features
🔍 Search weather by city name

🎨 Colorful gradient backgrounds change based on temperature

🎭 Weather-based advice (like staying hydrated or wearing sweaters)

🤗 Friendly tone with weather-related jokes and quotes

📱 Responsive design for desktop and mobile



🛠 Tech Stack
HTML5

CSS3

JavaScript (Vanilla)

WeatherAPI for real-time data

🚀 How to Run This Project
Clone the repository or Download ZIP


Create the following files in a folder:

index.html

style.css

script.js

Paste the corresponding code into each file (code provided in the repository).

Open index.html in your browser.


🔑 API Key Setup
Visit WeatherAPI.com and create a free account.

Replace the API key in script.js:
const apiKey = "YOUR_API_KEY_HERE";
